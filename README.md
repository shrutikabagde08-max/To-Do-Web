# Discipline Time

Discipline Time is a simple web app for managing daily tasks and building a better routine.

## Features

- Add tasks
- Complete tasks
- Delete tasks
- Task progress
- Calendar
- Notes
- Motivational thoughts
- Saves data using LocalStorage
- Responsive design

## Built With

- HTML
- CSS
- JavaScript

## Run

Open `index.html` in your browser.
